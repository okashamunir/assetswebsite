Image Hosting Service

This is a static image hosting service. Images are stored in the public directory and can be accessed via their URLs.

Note: This is a demo service. To upload images, place them in the /public/images directory and deploy to Vercel. After deployment, your images will be available at https://your-vercel-domain.com/images/filename.jpg
